Overview

A quick look at everything stored for this site, in this browser.

How this admin panel works: this is a static site with no server or database, so there's no real backend to save to. Everything you add here (projects, education, messages) is stored in this browser's local storage and appears immediately on the live pages when viewed on this device/browser — but it won't be visible to other visitors or other devices. Use the Site Content tab's "Export edits" to hand off a JSON snapshot to a developer if you want changes made permanent in the actual code.

Messages

Messages submitted through the Contact form.

Because this is a static site, messages only land here when someone submits the contact form in this same browser — there's no server collecting messages from every visitor automatically. For real visitors elsewhere, the contact form already opens their own email app addressed to you, which is the reliable delivery path. "Reply by Email" below opens your email app with the reply addressed and quoted — actually sending happens from there, since a static site can't send email on its own.
